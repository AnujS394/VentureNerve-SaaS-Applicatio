# 🚀 VentureNerve - AI-Powered Founder Intelligence Platform

VentureNerve is an AI-powered startup intelligence platform designed to help founders make smarter business decisions through strategic insights, financial intelligence, investor transparency, competitor tracking, and risk analysis.

The platform combines advanced analytics with AI-driven recommendations to give founders a complete view of their startup's health, growth opportunities, and operational performance.

# ⚙️ Installation

## Prerequisites

Make sure you have installed:

- Node.js (v18 or later)
- npm or yarn

Verify installation:

```bash
node -v
npm -v
```

---

## Clone Repository

```bash
git clone https://github.com/your-username/venturenerve.git

cd venturenerve
```

---

## Install Dependencies

```bash
npm install
```

or

```bash
yarn install
```

---

## Run Development Server

```bash
npm run dev
```

Application runs at:

```bash
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```

Preview build:

```bash
npm run preview
```
